# Seis preguntas

A one-page as-is questionnaire for sports coordination, in Spanish with English
sublines. Six questions up front, seven optional stages behind them.

**Nothing is sent anywhere.** The page has no backend and makes no network calls
apart from loading its two typefaces. Answers are held in the visitor's own
browser via `localStorage` while they type, so they can close the tab and come
back. Getting the answers out is the visitor's own act: copy to clipboard, open
a prefilled mail draft, or download a text file.

Published with GitHub Pages from `index.html` on `main`.
